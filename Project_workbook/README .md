Project Title: Predictive Modelling Air Quality in the North-West of Calgary based on weather data for At-Risk Populations 

The goal of our project is to develop a machine learning-based predictive model that integrates weather, wildfire, and air quality data to forecast pollution levels in Northwest Calgary, delivering real-time (predictive) early warnings to at-risk populations and supporting better public health and infrastructure decisions. Through the development of our machine learning (ML) model, the group aims to merge healthcare and analytical data to inform the public better. 

The Python Libraries and Machine Learning Models utilized for this project include (but are not limited to):
  1. Pandas
  2. NumPy
  3. Scikit Learning
  4. Matplotlib 
  5. Regression Models 
  6. Baseline Time Series Forecasting (XGBoost)
  7. Recurring Neural Networks (LSTM)

The documents as part of this submission include 3 data files (.csv), one .ipnyb file, one README file(.mb) and one final report (.pdf). 

Data files - air_quality_data.csv, combined_weather_data.csv, wildfire_data.csv
